# عرض «أثر | ذاكرة المدينة» — لمدينة تك (Madinah Tech)

**التشغيل:** افتحي `index.html` في Chrome أو Edge (يشتغل بدون إنترنت). على الآيباد: افتحي الرابط في Safari ثم «مشاركة ← إضافة إلى الشاشة الرئيسية».

## التحكم
- **نقرة / → / مسافة / PageDown:** التالي · **← / PageUp:** رجوع
- **F:** ملء الشاشة · **B:** أسود · **W:** أبيض · **P:** عرض المقدّمة (ملاحظات + مؤقت) · **G:** نظرة عامة · **رقم + Enter:** صفحة · **H:** مساعدة
- الآيباد: نقرة = التالي، نقرة على الحافة اليمنى = رجوع، ☰ = القائمة.
